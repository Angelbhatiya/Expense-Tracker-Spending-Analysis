# Expense-Tracker-Spending-Analysis
Developed a Python-based Expense Tracker using Pandas to record, organize, and analyze expenses from CSV files. The project calculates total and average spending, categorizes expenses, and performs monthly and payment-mode analysis. Matplotlib and Seaborn are used to visualize spending patterns and generate meaningful financial insights.

# Features
- Load expense records from a CSV file.
- Inspect and clean the dataset.
- Calculate total and average expenses.
- Identify the highest and lowest expenses.
- Analyze spending by category.
- Compare monthly expenses.
- Analyze expenses by payment mode.
- Create charts to understand spending patterns.
- Summarize useful financial insights.

# Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- CSV

# Data Visualization

I used Matplotlib and Seaborn to create visualizations such as:
- Category-wise expense chart
- Monthly spending chart
- Spending pattern visualizations
These visualizations make it easier to understand the data and identify spending patterns.

# Insights

The analysis helped me understand:
* Which category had the highest spending
* Which month had the highest expenditure
* The average amount spent per transaction
* The highest individual expense
* How spending was distributed across different categories
* How different payment methods were used
